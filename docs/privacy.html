隐私政策

每日一张 for Mac

每日一张是一个 macOS 菜单栏应用。它把每天的一张图片设为你的桌面。本政策说明它碰过哪些数据。

我们不收集数据

没有账号，没有广告，没有分析，也没有我们自己的服务器。开发者收不到你的姓名、照片或使用记录。

图片从哪里来

应用会向必应的公开图片接口请求当天的图片，然后下载到你的 Mac。这些请求由你的电脑直接发给必应，不经过我们。图片文件保存在本机：图库在应用自己的文件夹里，正在使用的壁纸在「图片 / 每日一张」。

本机保存的内容

市场、主题、是否自动更换，以及最近一次刷新的时间，写在本机的偏好设置里。只有这台 Mac 上的这个应用能读到。

联系

问题请写到 GitHub 仓库。

本应用与 Microsoft 无关。必应和每日图片的权利属于微软和拍摄者。
