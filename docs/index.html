What it does

设一次，然后忘掉它。

01

每天自己换

每 30 分钟检查新图。下载后会核对大小和格式，失败则退避重试，不会对着接口一直打。

02

只占菜单栏

预览、往前翻、立刻刷新、退出，都在弹出的小窗口里。没有 Dock 图标。

03

主题按天轮换

除了必应每日图片，还可以选主题合集。非每日主题每天换一张。

04

跟着市场走

中国、美国、日本等 12 个市场。标题和图片跟你选的市场一致，也能滤掉 AI 生成的图。

05

登录就在，醒来就补

第一次打开会打开「登录时启动」。睡眠期间计时不暂停，系统唤醒后马上再刷一次。

06

图片留在本地

文件在 ~/Library/Application Support/BingWallpaper。没有账号，也没有遥测。

Install

下载，拖进应用程序。

打开 DMG，把 Bing Wallpaper 拖进「应用程序」。这个包用 Developer ID 签名，并经过 Apple 公证。

  1. 下载 BingWallpaper-1.0.0.dmg。
  2. 打开磁盘映像，把应用拖到 Applications 文件夹。
  3. 从启动台打开。菜单栏出现图片图标后，今天的必应壁纸就会换上。

想改代码的话，仍可以用 macOS 14 和 Xcode 16 自己构建。仓库里的脚本默认是 ad-hoc 签名，只适合自己用。

git clone https://github.com/fairzy/bingwallpaper-for-mac.git
cd bingwallpaper-for-mac
scripts/build-app.sh
open build/BingWallpaper.app

Questions

开始之前

这是微软官方的 Mac 版吗？

不是。必应壁纸的官方应用只有 Windows 版。这个项目是独立的开源实现，不隶属于微软。Bing 名称和每日图片的版权仍属于微软和拍摄者。

哪些 Mac 能跑？

macOS 14 或更新版本。构建脚本同时编译 arm64 和 x86_64，Apple 芯片和 Intel 用同一份应用。

它会改我所有桌面吗？

macOS 只允许改当前 Space 的壁纸。切到另一个 Space 时，应用会再补设一次。

真的免费吗？

开源版免费，MIT 协议。源码在 GitHub 上。Mac App Store 上的「每天一张」即将上架，是另一个付费应用，售价 US$2.99。

App Store 版和开源版有什么不一样？

开源版是这个 DMG：免费，这台 Mac 直接向必应要图。App Store 版叫「每天一张」，Coming Soon。图片经过我们自己的服务器，所以官方接口失效之后，缓存过的图还能用。两个应用可以一起装。

图片存在哪里？

~/Library/Application Support/BingWallpaper。设置里有「在 Finder 中打开图片文件夹」。没有任何内容被上传。
